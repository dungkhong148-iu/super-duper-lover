SPEC B2 - Budgets tab                  (writer: head_agent, 2026-11-08; base commit e82d5b6)

GOAL
"Ngân sách" tab: pick a month, see that month's budgets with spent / remaining and a progress bar, add / edit / delete
budgets, copy last month's budgets.

ENV (every shell)
  . D:\android-tools\env.ps1
Check command: .\gradlew :core:test assembleDebug   (must end BUILD SUCCESSFUL)

FILE TO EDIT (only this one)
  app/src/main/java/com/superduperlover/finance/ui/budgets/BudgetsScreen.kt
It is a stub: `fun BudgetsScreen()` showing ComingSoon. Keep that exact signature (FinanceApp.kt already calls it).
Private composables in the same file are fine.

DO NOT TOUCH
  FinanceApp.kt, any other ui/ file, data/*, core/*, build files, libs.versions.toml, app/schemas/*, manifest.
  No new libraries, no material-icons-extended. Do not add new colours to Common.kt: define the amber colour
  privately in BudgetsScreen.kt (see Colours).

DATA (already built; `val repo = LocalRepo.current`, import com.superduperlover.finance.ui.LocalRepo)
  repo.budgets(month: YearMonth): Flow<List<Budget>>
  suspend repo.saveBudget(b: Budget): Long       // id = 0 inserts, otherwise updates
  suspend repo.deleteBudget(id: Long)
  repo.txns(month = month): Flow<List<Txn>>      // all accounts, all kinds, the month's own dates
  repo.accounts(includeArchived = true), repo.categories(CategoryKind.EXPENSE, includeArchived = true)
  core (package com.superduperlover.finance.core): Budget(id, month: YearMonth, accountId: Long?, categoryId: Long?, limit: Long),
    budgetUsage(budget, txns): BudgetUsage(spent, limit, remaining, ratio: Double, status: BudgetStatus {OK, WARN, OVER}),
    formatVnd(Long), parseVndInput(String): Long?
  Collect flows with collectAsState(initial = emptyList()); write in rememberCoroutineScope().launch { }.
  Do NOT recompute spent / status yourself: always call budgetUsage(budget, txnsOfThatMonth). ratio is display only.
  Budget.categoryId = null means "Tất cả danh mục"; accountId = null means "Tất cả tài khoản".

LAYOUT (Vietnamese text)
1. Month switcher row: IconButton(KeyboardArrowLeft, contentDescription "Tháng trước") | text "Tháng 11/2026"
   (titleLarge, centered, weight 1f) | IconButton(KeyboardArrowRight, "Tháng sau"). Both buttons min 48.dp.
   State: `rememberSaveable { mutableStateOf(YearMonth.now().toString()) }` and YearMonth.parse(...) (YearMonth itself is
   not saveable). Start = current month. No limit on going back/forward.
2. LazyColumn (keys = budget ids, contentPadding bottom 96.dp because the "+" FAB overlaps). Each budget = Card:
   - title: "<Tài khoản or 'Tất cả tài khoản'> · <Danh mục or 'Tất cả danh mục'>" (account / category names looked up
     by id from lists collected with includeArchived = true; unknown id -> "?").
   - LinearProgressIndicator(progress = { usage.ratio.toFloat().coerceIn(0f, 1f) }, color = status colour, min height 8.dp).
   - text line 1: "Đã chi ${formatVnd(spent)} / ${formatVnd(limit)}".
   - text line 2: remaining >= 0 -> "Còn lại ${formatVnd(remaining)}", otherwise "Vượt ${formatVnd(-remaining)}".
   - a status word next to the bar so colour is never the only cue: OK "Ổn", WARN "Sắp hết", OVER "Vượt mức".
   - tap the card -> edit sheet.
3. Empty state when the month has no budgets: text "Chưa có ngân sách cho tháng này".
4. Below the list (also visible when empty): Button "Thêm ngân sách" and OutlinedButton "Sao chép từ tháng trước".
5. Add/edit sheet: copy the structure of `AccountSheet` in ui/accounts/AccountsScreen.kt (ModalBottomSheet,
   skipPartiallyExpanded = true, verticalScroll + navigationBarsPadding + imePadding, spacedBy 12.dp):
   - label "Tài khoản": horizontally scrollable FilterChips: "Tất cả" + each non-archived account
     (plus the budget's current account if archived).
   - label "Danh mục": horizontally scrollable FilterChips: "Tất cả" + each non-archived EXPENSE category
     (plus the budget's current category if archived).
   - OutlinedTextField "Hạn mức (₫)", KeyboardType.Number, parsed with parseVndInput; null -> error
     "Số tiền không hợp lệ" under the field. Prefill with limit.toString() when editing.
   - Button "Lưu"; for an existing budget also OutlinedButton "Xóa ngân sách" (error colour) with an AlertDialog confirm
     "Xóa ngân sách này?" / "Xóa" / "Hủy".
   - Duplicate rule: in one month there may be only one budget per (accountId, categoryId) pair. If saving would make a
     second one (ignoring the budget being edited) -> error "Ngân sách này đã tồn tại" and do not save.
   - Saved budget: Budget(id, month = shown month, accountId, categoryId, limit).

COLOURS (status bar + status word)
  OK   -> incomeColor()  (green)    WARN -> amber, private val in this file: light 0xFFB26A00, dark 0xFFFFB74D
  OVER -> expenseColor() (red)
  incomeColor() / expenseColor() are in ui/components/Common.kt. Pick amber with isSystemInDarkTheme().

"SAO CHÉP TỪ THÁNG TRƯỚC"
  Read last month with repo.budgets(month.minusMonths(1)).first() (import kotlinx.coroutines.flow.first).
  For each, unless the shown month already has a budget with the same (accountId, categoryId):
  repo.saveBudget(b.copy(id = 0, month = shownMonth)). If last month has none, show a short message under the buttons:
  "Tháng trước chưa có ngân sách". If everything already exists show "Đã có đủ ngân sách". Otherwise no message.

HOW TO CHECK (no UI/e2e tests, rule 14)
1. .\gradlew :core:test assembleDebug -> BUILD SUCCESSFUL.
2. Read your diff against this spec: only BudgetsScreen.kt changed (`git status`), status comes from budgetUsage,
   no Double used for amounts (ratio only for the bar), spent exactly equal to limit -> WARN (amber), limit + 1 -> OVER,

3. Hand-math case the director will try on the phone: account A budget 1.000.000 ₫; expense 800.000 -> "Sắp hết" amber,
   remaining 200.000; add 200.000 -> exactly the limit, still amber, "Còn lại 0 ₫"; add 1 more -> red "Vượt 1 ₫";
   a transfer or income never changes it; an expense dated last month changes only last month's budget.
