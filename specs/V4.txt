PART A - theme mode
  AppPrefs.kt (package com.superduperlover.finance.ui.theme):
    enum class ThemeMode { SYSTEM, LIGHT, DARK }
    class AppPrefs(context: Context): wraps context.getSharedPreferences("chili_prefs", Context.MODE_PRIVATE).
        var themeMode: ThemeMode  - Compose state (mutableStateOf) initialised from the stored name (unknown / missing -> SYSTEM); the setter also writes the preference (apply()).
        var summaryCurrency: Currency?  - same pattern (stored by name; null = never chosen).
    val LocalAppPrefs = staticCompositionLocalOf<AppPrefs> { error("AppPrefs not provided") }
  Theme.kt: FinanceTheme(content) reads LocalAppPrefs.current.themeMode: SYSTEM -> isSystemInDarkTheme(), LIGHT -> false, DARK -> true. Everything else (tokens, schemes) is already there.
  MainActivity.kt: build `val prefs = AppPrefs(applicationContext)` once, provide LocalAppPrefs (next to LocalRepo). System bars: the icons must stay readable in the forced mode:
    inside setContent, compute `val dark = <same rule as FinanceTheme>` and run
      DisposableEffect(dark) { enableEdgeToEdge(statusBarStyle = SystemBarStyle.auto(Color.TRANSPARENT, Color.TRANSPARENT) { dark }, navigationBarStyle = SystemBarStyle.auto(Color.TRANSPARENT, Color.TRANSPARENT) { dark }); onDispose {} }
    (androidx.activity.SystemBarStyle; remove the plain enableEdgeToEdge() call before setContent or keep it, but the effect must win).
  AppearanceScreen.kt: `fun AppearanceScreen(onBack: () -> Unit)`: ChiLiTopBar("Giao diện", onBack), a SectionCard with three rows (each >= 56dp, the whole row selectable with Modifier.selectable(role = Role.RadioButton)):
    RadioButton + "Theo hệ thống" (sub line "Sáng hoặc tối theo cài đặt điện thoại"), "Sáng", "Tối". Selecting writes AppPrefs.themeMode at once (the app recolours immediately).
  SettingsTabScreen.kt: new row "Giao diện" first in the list (subtitle = current choice's name), chevron, click -> onOpenAppearance. New signature:
    fun SettingsTabScreen(onOpenCategories: () -> Unit, onOpenBackup: () -> Unit, onOpenAppearance: () -> Unit)
  FinanceApp.kt: add composable("appearance") { AppearanceScreen(onBack = { navController.popBackStack() }) } and pass onOpenAppearance = { navController.navigate("appearance") }.

PART B - Home summary card (AccountsPage.kt)
  - Chips: a Row(horizontalScroll) of FilterChip, one per currency in CURRENCY_DISPLAY_ORDER that has at least one (non-archived) account, label = "TWD" style code (Currency.name), min height 48dp.
    Hidden when only one currency exists.
  - Selected currency: AppPrefs.summaryCurrency if it is among the available ones; else MAIN_CURRENCY (TWD) if available; else the first available. Choosing a chip writes AppPrefs.summaryCurrency.
  - The whole card follows the selected currency: "Tổng số dư" = balancesByCurrency(...)[currency]; "Còn được tiêu <period label>" = sum of `remaining` of the CURRENT period of the overall budgets
    (categoryId == null) in that currency (budgetUsage(..., today)); period label from BudgetPeriod.thisLabel() when all those budgets share one period, otherwise "kỳ này"; "Thu nhập" / "Chi tiêu" of this calendar month
    = txnTotals(monthTxns, accounts)[currency]. If that currency has no overall budget: the existing "Chưa có ngân sách tổng" + "Tạo ngân sách" row.
    The card shows exactly ONE amount per line now (no side-by-side currencies, no FlowRow).
  - Tiles and "Ngân sách cần chú ý" stay as they are (all currencies).
