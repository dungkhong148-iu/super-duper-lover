THE HOST: ui/components/FormDialog.kt
  @Composable fun FormDialog(title: String, onClose: () -> Unit, onSave: () -> Unit, saveEnabled: Boolean, hasChanges: Boolean, content: @Composable ColumnScope.() -> Unit)
  - Dialog(onDismissRequest = request close, properties = DialogProperties(usePlatformDefaultWidth = false, decorFitsSystemWindows = false)) so it fills the screen.
  - Inside: Surface(color = MaterialTheme.colorScheme.background) { FullScreenForm(...) } with Modifier.fillMaxSize().systemBarsPadding().
    FullScreenForm (ui/components/FullScreenForm.kt, already written: ✕ title ✓ + scrolling content, handles imePadding) must not be edited.
  - Close request (✕, system back, tap outside): if hasChanges -> AlertDialog "Bỏ thay đổi?" / confirm "Bỏ" / dismiss "Tiếp tục sửa"; else onClose() at once.
  - hasChanges = the form state differs from the values it started with (compute in each form).
  Call sites keep doing `editing?.let { X(..., onDismiss = { editing = null }) }`; the form calls onDismiss() after a successful save / archive / delete / discard.

COMMON RULES FOR ALL FOUR FORMS
  - Group the fields under SectionHeaderBand (ui/components/SectionCard.kt) strips; content padding 16dp horizontally, 12dp between fields; each field: label above (OutlinedTextField label is fine), error text right under the field.
  - ✓ (saveEnabled) is false while the required fields are empty (name, amount ...). When the user taps ✓ and a deeper check fails (not parseable amount, duplicate...), show the error under the field exactly as today.
  - KEEP all current logic and all current messages (validation texts, delete guards, duplicate rule, uniqueness rule); only the container and layout change. Read the current file first and port it.
  - Destructive actions (Lưu trữ, Xóa) move to the bottom of the form as full-width TextButtons / OutlinedButtons in the error colour for delete, under their own header band "Khác" (only for existing items). Delete keeps its confirm or guard as today.
  - Money fields: parseAmount(text, currency) / amountToInput / currencySymbol from core; currency picker = CurrencyChips (ui/components/CurrencyChips.kt).
  - Colours only from theme tokens; text >= 14sp for fields; single-line labels via OneLineText; touch targets >= 48dp; looks right at font scale 1.0 and 1.25.
