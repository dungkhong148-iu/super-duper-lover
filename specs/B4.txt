    /** Sum of INCOME and of EXPENSE amounts. TRANSFER is ignored. */

STEP 2 - screen changes in TransactionsScreen.kt
  Data (already built; `val repo = LocalRepo.current`):
    repo.txns(month: YearMonth? = null, accountId: Long? = null, categoryId: Long? = null): Flow<List<Txn>>
    (newest first; accountId also matches transfers INTO that account), repo.accounts(includeArchived = true),
    repo.categories(includeArchived = true).
  1. Month state: `rememberSaveable { mutableStateOf(YearMonth.now().toString()) }` + YearMonth.parse (YearMonth is not saveable).
     Replace the fixed `month` with it. The existing title "Tháng M/yyyy" becomes the month switcher row:
     IconButton(KeyboardArrowLeft, contentDescription "Tháng trước") | "Tháng 11/2026" (titleLarge, centered, weight 1f) |
     IconButton(KeyboardArrowRight, "Tháng sau"); buttons min 48.dp.
  2. Filter state (rememberSaveable): accountId: Long? and categoryId: Long? (null = all). Query:
     repo.txns(month, accountId, categoryId) -- re-collect when the state changes (use `remember(month, accountId, categoryId) { repo.txns(...) }`
     then collectAsState).
  3. Filter row (horizontally scrollable, under the switcher): two dropdown-style FilterChips
     "Tài khoản: Tất cả" / "Tài khoản: <name>" and "Danh mục: Tất cả" / "Danh mục: <name>". Tap opens a DropdownMenu with
     "Tất cả" first and then the items (accounts: non-archived plus the selected one; categories: all categories incl. archived,
     with the kind in brackets if two share a name, e.g. "Khác (Chi tiêu)"). Choosing an item sets the state and closes the menu.
     A TextButton "Xóa bộ lọc" appears only when any filter or search text is active and resets all of them.
  4. Search: an IconButton (Icons.Filled.Search, contentDescription "Tìm kiếm") at the right of the month row toggles an
     OutlinedTextField "Tìm trong ghi chú" (singleLine) under the filter row. Filter the loaded list on the client:
     keep a txn when search text (trimmed) is empty or txn.note contains it, ignoring case. Search text is rememberSaveable.
  5. Totals card under the filters: two columns "Thu nhập" (green, incomeColor(), format "+${formatVnd(income)}") and
     "Chi tiêu" (red, expenseColor(), format "-${formatVnd(expense)}"). Values = txnTotals(listAfterSearch) from core.
     Both labels are text, colour is only extra. incomeColor()/expenseColor() are in ui/components/Common.kt.
     Totals follow the month AND the active filters AND the search (they describe exactly the rows shown).
  6. Empty state: if the shown list is empty and any filter/search is active show "Không có giao dịch phù hợp"
     (and the "Xóa bộ lọc" button stays reachable); with no filters keep the current message
     "Chưa có giao dịch trong tháng M/yyyy". The month switcher, filters and totals must stay visible in the empty state
     (restructure so the header is always shown, e.g. header items at the top of the LazyColumn, with an extra item for the
     empty message).
  7. Keep keys unique in the LazyColumn ("month" key is gone; use "header", "filters", "totals", "day-$date", txn ids).
