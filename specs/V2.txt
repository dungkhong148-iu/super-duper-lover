SPEC V2 - Budgets UI: repeating periods, start date, rollover     (writer: head_agent, 2026-11-08; base commit 1846dac)

GOAL
Budgets now repeat every period (Ngày / Tuần / Tháng / Quý / Năm), counted from a start date the user picks, with an optional rollover.
The core, the database and the repository already do all the maths (V1). This task is the UI: the budget form and the budget cards.
Read first: docs/ui-layout.md sections 2, 3, 4, 5, 7 and the spec section "Budget periods" (docs/superpowers/specs/2026-11-08-finance-app-design.md, end).
Skill for visual decisions: .agents/skills/ui-ux-pro-max (search with --stack jetpack-compose; forms, switches, lists).

Check command: .\gradlew :core:test assembleDebug   (must end BUILD SUCCESSFUL)

  EDIT app/src/main/java/com/superduperlover/finance/ui/budgets/BudgetSheet.kt        the full-screen form (FormDialog): add period, start date, rollover

ALREADY AVAILABLE (read their code, do not change)
  core (package com.superduperlover.finance.core):
    enum BudgetPeriod { DAY, WEEK, MONTH, QUARTER, YEAR }
    data class Budget(id, period, startDate: LocalDate, accountId, categoryId, limit: Long, currency, rollover: Boolean)   // there is NO month any more
    data class PeriodRange(start: LocalDate, endInclusive: LocalDate)
    periodRange(period, startDate, index): PeriodRange      // index 0 = first period; use it to PREVIEW the first range while the user edits
    budgetUsage(budget, txns, accounts, today): BudgetUsage(spent, limit, remaining, ratio, status, range, carried) with effectiveLimit = limit + carried
       - range = the CURRENT period (the one that contains today); remaining and status are against effectiveLimit.
       - txns must be ALL transactions (repo.txns()), accounts ALL accounts incl. archived (repo.accounts(includeArchived = true)). BudgetsScreen already loads them so.
    formatMoney(amount, currency), parseAmount, amountToInput, currencySymbol
  data: LocalRepo.current -> repo.budgets() (all budgets), repo.saveBudget(budget), repo.deleteBudget(id)
  ui: FormDialog (ui/components/FormDialog.kt), SectionHeaderBand / SectionCard (components/SectionCard.kt), OneLineText, CurrencyChips, EmptyState,
      thisLabel() for BudgetPeriod in components/Common.kt ("tháng này"...), theme tokens (ChiLiTheme.colors, MaterialTheme.colorScheme).
  Read the CURRENT BudgetSheet.kt and BudgetsScreen.kt first: the form already has account chips, category chips, currency chips, limit field, duplicate rule, delete with confirm.
  BudgetSheet saves with `budget.copy(accountId, categoryId, limit, currency)`: period / startDate / rollover are kept from the budget it was opened with. This task makes them editable.

    Empty state (existing) text: title "Hãy tạo ngân sách đầu tiên", message "Đặt hạn mức theo ngày, tuần, tháng, quý hoặc năm để biết còn được tiêu bao nhiêu.".
