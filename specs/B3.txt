GOALS TAB (GoalsScreen)
- LazyColumn (keys = goal ids, contentPadding bottom 96.dp because the "+" FAB overlaps).
- One Card per goal, tap -> onOpenGoal(goal.id). A private composable GoalCard(goal) collects
  repo.contributions(goal.id) itself and calls goalProgress(goal, contributions, LocalDate.now()).
  Content: name (titleMedium); LinearProgressIndicator(progress = { ratio.toFloat().coerceIn(0f, 1f) }, min height 8.dp);
  "Đã để dành ${formatVnd(saved)} / ${formatVnd(goal.target)}"; then
    - not done and perMonth != null -> "Cần để dành ${formatVnd(perMonth)}/tháng"
    - not done and deadline = null  -> no per-month line
    - done -> a "Đã đạt mục tiêu" label (primary colour, with a Check icon from material-icons-core) and NO per-month line
  When goal.deadline != null show "Hạn: dd/MM/yyyy".
- Empty state: "Chưa có mục tiêu nào".
- Button "Thêm mục tiêu" under the list -> add sheet (below).

GOAL SHEET (add and edit; copy the structure of AccountSheet in ui/accounts/AccountsScreen.kt)
  ModalBottomSheet(skipPartiallyExpanded = true), verticalScroll + navigationBarsPadding + imePadding, spacedBy 12.dp.
  - OutlinedTextField "Tên mục tiêu" -> trimmed, empty -> error "Nhập tên mục tiêu".
  - OutlinedTextField "Số tiền mục tiêu (₫)", KeyboardType.Number, parseVndInput; null -> "Số tiền không hợp lệ".
  - Deadline (optional): OutlinedButton showing "Chưa đặt hạn" or the date; tap opens the Material3 DatePickerDialog
    (same pattern as AddTransactionScreen.kt: rememberDatePickerState(initialSelectedDateMillis = epochDay * 86_400_000L),
    result = Math.floorDiv(millis, 86_400_000L) -> LocalDate.ofEpochDay). A TextButton "Bỏ hạn" clears it.
  - Button "Lưu" -> repo.saveGoal(Goal(id, name, target, deadline)). Keep archived = false.

DETAIL SCREEN (GoalDetailScreen)
- Top row: IconButton(ArrowBack, "Quay lại", onClick = onBack) + goal name.
- Summary card with the same progress content as GoalCard (bar, saved / target, per-month line or done label, deadline).
- Buttons: Button "Thêm khoản để dành", OutlinedButton "Sửa mục tiêu" (opens the goal sheet prefilled),
  OutlinedButton "Lưu trữ mục tiêu" with AlertDialog confirm "Lưu trữ mục tiêu này?" / "Lưu trữ" / "Hủy" ->
  repo.archiveGoal(id) then onBack().
- Contributions list (LazyColumn, keys = contribution ids): row = date (dd/MM/yyyy) + amount (formatVnd, green via
  incomeColor() from ui/components/Common.kt). Tap a row -> contribution sheet prefilled (edit). Empty: "Chưa có khoản nào".
- Contribution sheet: OutlinedTextField "Số tiền (₫)" (parseVndInput; error "Số tiền không hợp lệ"), date button
  (default today, DatePickerDialog as above), Button "Lưu" -> repo.addContribution(GoalContribution(id, goalId, amount, date))
  (id = 0 for new, existing id for edit). In edit mode the sheet also has a TextButton "Xóa" (error colour) that opens an
  AlertDialog "Xóa khoản này?" / confirm "Xóa" / dismiss "Hủy"; confirm -> repo.deleteContribution(id), close dialog and sheet.
- Contributions are tracked separately from accounts: they never change any account balance. Do not touch transactions.
